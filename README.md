- Rider: rider@reyed.demo / rider123

New in v5:
- Business and street autocomplete with nearby suggestions
- Reverse geocoding when the rider taps the map
- Available-rides map on the driver page
- Full pickup, drop-off, rider, offer, time, and distance details
- Driver workflow: Accept → Arrived → Pick up → Drop off
- Detailed rider current ride and ride history
- Fresh demo database key plus an open sample ride

This uses Nominatim/OpenStreetMap for search and map labels. GitHub Pages remains a static same-browser demo. True multi-device accounts and real-time syncing require Firebase or Supabase.
